# jogos-matematikes

Jogos de matemática em HTML (um arquivo por jogo, sem instalação), para uso em sala de aula do 6º ao 9º ano.
Cada jogo fica na sua pasta (`Pasta/index.html`); a página inicial (`index.html`) reúne todos por tema.

© Ygor B. F. Ferreira · A Saga dos Reinos Matemáticos · Matematkês · uso livre em sala.

Observação: Travessia e Câmara das Formas carregam estilos de um serviço externo (Tailwind) e fontes do Google; precisam de internet na primeira abertura.
